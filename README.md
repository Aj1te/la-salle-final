# 🏋️‍♂️ La Salle de Sport **Le Studio** – Biarritz

Bienvenue sur le site vitrine de **Le Studio**, une salle de sport moderne située à Biarritz ! 
Ce projet a été conçu pour offrir une vitrine en ligne claire, responsive et attrayante, qui reflète l’esprit dynamique et élégant de la salle.

## ✨ Présentation

> *"Un site web, c’est comme une salle de sport : ça doit être bien structuré, bien animé, et donner envie d’y rester."*

Ce site vitrine a pour objectif de :
- Présenter **Le Studio** et ses services.
- Mettre en avant les cours, coachs et formules d’abonnement.
- Faciliter la prise de contact avec les visiteurs.

## 👥 Projet réalisé en binôme

Ce projet a été conçu à deux dans le cadre de notre formation en développement web. L’idée était de simuler une commande client pour un site vitrine local.

## 🛠️ Technologies utilisées

- **HTML5**
- **CSS3**
- **Bootstrap 4.5 (via CDN)**
- **JavaScript Vanilla**

Le tout conçu en respectant une logique responsive pour une navigation fluide sur tous les supports 📱💻🖥️
